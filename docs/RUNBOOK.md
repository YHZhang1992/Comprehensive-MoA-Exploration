# Runbook

1. Prepare one row per unique gene with model, treatment, human, pathway, and network fields.
2. Record organism, tissue, time point, assay, normalization, contrast, and reference releases outside the input table.
3. Run the synthetic fixture and tests before substituting real data.
4. Use a new output directory for every run and retain the checksum-bearing manifest.
5. Review component scores separately; the composite ranking is a prioritization aid, not causal evidence.
